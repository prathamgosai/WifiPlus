Phase 3

Design Strategy

One thesis: make the measurement the hero, make everything else quiet. The product's magic is a real, live network reading — so the interface should feel like precision instrumentation, not a marketing site with a widget bolted on.

Principles

  • Instrument, don't decorate. Live numbers, sparklines, and state chips carry the page — motion serves meaning.
  • One decision per screen. A single primary action, obvious at a glance; secondary paths recede.
  • Earn trust with evidence. Replace "sample data" apologies with methodology, real result cards, and honest labels.
  • Space is a feature. Halve the density; let the 8pt rhythm breathe so the eye lands where it should.

Conventions

  • Variables, 3 tiers. primitive/indigo-500 → semantic/brand → comp/button-bg
  • Modes. A single Variable collection with Light / Dark modes; every screen inherits.
  • Naming. Component/Property=Value — e.g. Button/variant=primary, size=md, state=hover
  • Auto Layout everywhere. Hug/fill, 8pt gaps, min-width guards for responsive resize.
  • Stitch-ready. Screens map 1:1 to Stitch: one frame = one screen, tokens exported as a theme, components as Stitch design-system entries.

Phase 7

Conversion Optimization

Hero

Run the test in the first viewport

Today the hero splits attention between two CTAs and a wall of copy. New: one primary "Start speed test", the live instrument as proof, a rotating sub-headline. Expected: lower bounce, higher activation — the aha-moment happens before any scroll.

Trust

Turn disclaimers into credibility

"This static prototype uses demo data" appears repeatedly and quietly kills trust. Replace with a methodology strip ("measured from real bytes, median latency, ramp discarded"), a real result card, and clearly-labelled sample vs. measured data. Honesty stays; the framing flips from apology to authority.

Social proof

Add evidence a human left

Zero testimonials, logos, or usage numbers today. Add an infinite logo/marquee of "measured on" ISPs, attributed reviews, and a live "N tests run today" counter. Placeholders must be labelled until real proof exists — never fabricate reviews.

Pricing

Give the funnel a destination

There is no pricing and no email capture — the site has nowhere to convert. Add the 3-tier table, a free-forever anchor, and a newsletter capture in the footer. A clear "free" anchor de-risks the upgrade.

FAQ & CTA

Answer the real objections, then close

Reframe FAQ around "is this real?", "what happens to my screenshot?", "why differ from other tests?". End every major section with a single contextual CTA rather than repeating the same button. Objection-handling copy converts skeptics of a measurement tool.

Phase 11

AI Image & Asset Direction

Prompts and specs for the few generated assets this design needs — used sparingly, because the live instrument is the real hero.

Hero ambient (CSS, not image)

Aurora mesh: 3 radial fields (violet/indigo/cyan at 8–18% alpha) + faint 56px grid with a top-fade mask. Zero network cost — already rendering behind this page.

Empty-state illustration (Lottie)

"Minimal line-art radar sweep over a globe, indigo→cyan gradient stroke, dark transparent bg, single subtle loop, no text, 2px strokes." For "run your first test".

3D signal object (spot use)

"Frosted-glass torus knot emitting concentric signal rings, soft indigo rim light, cyan bloom, floating on deep navy, studio render, subtle depth of field." Pricing/CTA accent only.

Iconography

Lucide, 1.75px stroke, inside glass orbs with a tone-matched inner glow. Never emoji. Consistent 20/24px grid.

OG / social card

1200×630, dark ground, signal gradient bar, live-metric tiles, wordmark + signal arcs. PNG (SVG is rejected by social scrapers).

Patterns & texture

SVG fractal-noise film grain at 3–4% opacity, overlay blend. Mesh-gradient blobs on the compositor. No stock photography anywhere.
