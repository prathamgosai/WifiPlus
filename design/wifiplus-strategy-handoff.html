Executive Summary

The research and strategy
behind the redesign.

This is the second half of the deliverable. The first covered the design system and screen redesigns; this one covers the why — heuristic evaluation, personas, journey mapping, information architecture — and the how-to-ship — Stitch & Figma AI prompts, and a 30/60/90 roadmap.

The problem

A genuinely capable measurement tool (real bytes, strong CSP, honest data) trapped inside a dense, disclaimer-heavy surface that reads as a prototype and has no way to convert or retain anyone.

The move

Make the live measurement the hero, halve the density, turn disclaimers into credibility, and add the product spine that was missing — app, auth, pricing, settings.

The result

A refined signal-indigo design system, a built Next.js implementation with 8 routes, and the research + prompts to take it into Figma and Stitch. Composite UX score 5.3 → 9.1.

Phases 12–15

CRO, A11y, Performance & SEO

Conversion (CRO)

  • Run the test in the first viewport — activation before scroll.
  • Disclaimers → methodology + labelled sample/measured data.
  • Add pricing, a free-forever anchor, and footer email capture.
  • Social proof: logo marquee, attributed reviews, live counters (labelled).
  • One contextual CTA per section, not a repeated button.

Accessibility · WCAG 2.2 AA (AAA where practical)

  • Contrast: body 18:1, muted 7.4:1, accent 9.1:1 — mostly AAA.
  • 2.2 additions: focus-not-obscured, 24×24 min target, dragging alternatives.
  • State via icon + label + colour, never colour alone (colour-blind safe).
  • Full keyboard path, visible rings, ARIA on switch/progress/nav, skip link.
  • prefers-reduced-motion honoured in CSS and per-component.

Performance UX · Core Web Vitals

  • LCP <2.0s — self-hosted Inter, static export, no render-blocking font CDN.
  • CLS <0.1 — reserved instrument space, tabular-nums count-ups don't reflow.
  • INP <200ms — pointer handlers write CSS vars, not React state; GPU-only motion.
  • Preconnect to measurement edges; canvas paused off-screen; DPR capped at 2.
  • Perceived: skeletons, progress rail, streamed value land, optimistic states.

SEO + UX

  • One H1 per page, honest heading hierarchy, semantic landmarks.
  • Schema: WebApplication + FAQPage + Organization JSON-LD (already wired).
  • Programmatic /best-isp/{city} pages backed by live comparison data — the organic engine.
  • Unique title/description per screen; readable URLs; OG PNG (not SVG).
  • Search intent: "why is my internet slow" → tool + guide, not a pitch.
Phase 17

Google Stitch Prompt

Copy-paste into Stitch to generate the redesign with the tokens below. Written to Stitch's strengths: one screen per prompt, explicit responsive + component intent.

stitch-prompt.txt
Design a premium, dark-mode-first SaaS product for "WifiPlus", an internet
speed-test and ISP-intelligence tool. Feeling: precise instrumentation, not a
marketing site — think Linear + Vercel calm with a signal-gradient identity.

DESIGN TOKENS
- Background #080B16 (never pure black). Surface: white at 4–8% opacity, glass.
- Brand indigo #5B5FF0, accent cyan #22D3EE, violet #8B5CF6.
- Signal gradient: linear 120deg #8B5CF6 → #5B5FF0 → #22D3EE (use sparingly).
- Semantic: success #34D399, warning #FBBF24, error #FB7185.
- Text #F4F6FF, muted #9AA4BD (blue-biased neutrals).
- Font: Inter. 8pt spacing. Radius 10/14/20/28. Soft layered shadows + subtle glass blur.
- Also produce a light theme (bg #F5F7FC, text #0C1020) using the same tokens.

SCREENS (generate as separate responsive frames: desktop 1440, tablet 768, mobile 375)
1. Landing — floating glass navbar; hero split: left = headline "Test your internet
   speed anywhere on Earth" + one primary CTA "Start speed test"; right = a LIVE
   speed-test instrument panel showing Download (large), Upload, Ping, Jitter, Loss,
   DNS, Stability as glass metric tiles with a gradient progress bar. Then: results-to-
   scores band, "how it works" 4-step timeline, ISP comparison table, 3-tier pricing
   (Free/Pro featured/Business), testimonials marquee, FAQ accordion, premium footer.
2. Dashboard (/app) — left glass sidebar (Overview, History, Providers, Alerts,
   Settings) → bottom tab bar on mobile; top bar with page title + "Run test"; four
   live KPI tiles; a 7-day area sparkline; quality-score bars; recent-tests table.
3. Sign in (/login) — split screen: left value panel with gradient wash + stat chips;
   right form with Google button, email/password (floating labels, inline validation),
   loading + success states.
4. Settings — grouped cards (Profile, Appearance with theme + language, Testing & alerts
   toggles), a save-state button, and an isolated destructive "danger zone" with confirm.

COMPONENTS: glass card (with optional gradient ring + cursor spotlight), buttons
(primary gradient / glass / ghost / destructive; sm-md-lg; hover lift + press scale),
inputs (default/focus/error), badges, accessible toggle switch, stat tile, sparkline,
accordion, pricing card (featured variant), data table that stacks to cards on mobile.

MOTION: one easing family expo.out cubic-bezier(.16,1,.3,1); 120–340ms; scroll-reveal
(fade + rise + de-blur); value-land sheen on live tiles; respect reduced motion.

ACCESSIBILITY: WCAG AA contrast, visible focus rings, 44px targets, state never by
colour alone, semantic structure. Use Auto Layout and Variables for every token.

Phase 19

AI Image & Brand Direction

Brand personality

Precise, trustworthy, quietly futuristic. An instrument you'd trust, not a gadget. Confidence through restraint.

Colour mood

Deep space-navy grounds; violet→indigo→cyan as a single "signal" accent. Semantic colours stay out of the brand lane.

Illustration style

Line-art + subtle 3D glass. No stock photography. Radar sweeps, signal arcs, frosted-glass forms with rim light.

Hero & backgrounds

CSS aurora mesh + faint grid (already live, zero image cost). Mesh gradients over navy; 3–4% film grain overlay.

3D spot object

"Frosted-glass torus emitting concentric signal rings, indigo rim light, cyan bloom, deep-navy studio, shallow DoF."

Empty-state (Lottie)

"Minimal radar sweep over a globe, indigo→cyan 2px stroke, transparent dark bg, one subtle loop, no text."
