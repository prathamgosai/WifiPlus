Implementation notes

This prototype is static and mobile-first. The speed test performs real measurements against a public global edge network; the ISP dataset and rankings are still representative seed data.

Can this support 200+ countries?

Yes by design. The data model stores country, state, city, ISP, plan, review, speed result, coverage, and ranking entities. The included dataset is representative seed data for the prototype.

How does automatic ISP expansion work?

A production ingestion pipeline pulls regulator files, provider feeds, public datasets, partner APIs, and user submissions into normalized PostgreSQL tables with verification workflows.

How are real speed tests measured?

Download and upload throughput are measured by moving real bytes over parallel HTTP streams against the nearest Cloudflare edge, discarding the first half-second while the congestion window ramps. Ping, jitter, and packet loss come from repeated timed probes; DNS latency comes from uncached DNS-over-HTTPS lookups.

Does PWA support work from a file?

The page opens directly as HTML. Service worker offline caching works when hosted over HTTPS or localhost.
